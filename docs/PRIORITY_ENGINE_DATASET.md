## Class-imbalance handling

- Models use `class_weight="balanced"` (see `backend/services/priority_model.py`).
- Reports use macro-F1 and per-class recall, never accuracy alone.
- `python -m scripts.suggest_labeling_batch` proposes unlabeled emails that are likely to belong to the under-represented classes so new labeling effort goes where it is needed. Candidates are heuristic suggestions only; labels must still be assigned by a person.
